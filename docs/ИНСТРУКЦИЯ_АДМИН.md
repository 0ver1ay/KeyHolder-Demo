# Ключница — инструкция для администратора

Краткое руководство по **административной программе** (настройка системы, пользователи, ключи, отчёты).

---

## Назначение

Админ-программа нужна для:
- учёта пользователей и RFID-меток;
- создания помещений, ключей и боксов (шкафов);
- выдачи прав «кто какой ключ может взять»;
- просмотра выдач, экспорта и фотосессий.

При запуске сразу открывается **Админ-панель** — сетка пунктов меню.

---

## Меню админ-панели

### Пользователи

| Пункт меню | Что делает |
|------------|------------|
| **Создать пользователя** | Новая учётная запись: логин и пароль (обязательно), телефон и комментарий (по желанию). После создания можно сразу привязать RFID-метку пользователя. |
| **Выдача привилегий** | Выбрать пользователя и бокс → отметить, к каким ключам у него есть доступ (нажатие на плитку ключа). |
| **Удалить пользователя** | Удалить учётную запись из системы. |

**Привязка RFID пользователя** (экран после создания или отдельно):
- «Приложите RFID-метку к считывателю» — привязка личной метки к пользователю.
- **Пропустить** — можно привязать позже.

---

### Помещения, ключи и боксы

| Пункт меню | Что делает |
|------------|------------|
| **Создать помещение/ключ** | Добавить помещение (кабинет, зона) и при необходимости ключ к нему. |
| **Создать бокс** | Новый шкаф/бокс: название, размер сетки ячеек (столбцы × строки). |
| **Удалить помещение** | Удалить помещение из справочника. |
| **Удалить бокс** | Удалить бокс. |
| **Назначить ключи на бокс** | Выбрать бокс → отметить, какие ключи в нём лежат и в каких ячейках (привязка к физическим слотам шкафа). |

> **Бокс** — физический шкаф с ячейками. **Ключ** привязан к помещению и к ячейке в боксе.

---

### RFID и секретные коды

| Пункт меню | Что делает |
|------------|------------|
| **Регистрация RFID ключа** | Выбрать ключ → **Ждать RFID** → приложить метку на ключевой брелок. Метка сохраняется за этим ключом. |
| **Секретные коды** | Для выбранного ключа задать код сдачи **без** входа пользователя в систему (кнопка «Сдать по секретному коду» в пользовательской программе). |

---

### Контроль и отчёты

| Пункт меню | Что делает |
|------------|------------|
| **Выданные ключи** | Кто сейчас держит какие ключи. Фильтр по названию/коду, листание страниц. |
| **Экспорт выдач** | Журнал операций (взял/сдал) за выбранный период. Фильтры по дате, пользователю, ключу, боксу. Данные можно выгрузить в файл. |
| **Снимки (сессии)** | Фото с камеры во время сессий пользователя. Выбор периода, список сессий, просмотр снимков. |

---

## Экран «Выдача привилегий» — подробнее

1. Вверху выберите **Пользователя** и **Бокс**.
2. Ниже — плитки ключей этого бокса.
3. Нажмите на плитку — доступ **включён/выключен** (цвет/состояние меняется).
4. **Назад** — в меню.
5. **Сбросить все выдачи** — принудительно снять все ключи в системе («все ключи на месте»). Использовать осторожно, только если нужно исправить рассинхрон с реальностью.

---

## Экран «Назначить ключи на бокс» — подробнее

1. Выберите **бокс** из списка.
2. Отметьте ключи, которые должны находиться в этом боксе.
3. Для каждого ключа задаётся **позиция в сетке** (строка/столбец ячейки) — это координаты для оборудования шкафа.
4. **Обновить** — перечитать список после изменений.

---

## Экран «Экспорт выдач» — подробнее

- Задайте **период** (дата от / до).
- В таблице — дата, пользователь, ключ, действие (выдача/сдача), бокс.
- Поля фильтра над таблицей сужают список.
- Кнопка экспорта сохраняет данные в файл (для отчётности).

---

## Экран «Снимки (сессии)» — подробнее

- Слева — список сессий за выбранный период.
- Справа — фотографии выбранной сессии (если камера была подключена и работала).
- Используется для контроля: кто и когда работал у шкафа.

---

## Типовой порядок первичной настройки

1. **Создать бокс** (шкаф) с нужным размером сетки.
2. **Создать помещения/ключи**.
3. **Назначить ключи на бокс** (привязка к ячейкам).
4. **Создать пользователей** + привязать RFID-метки.
5. **Выдача привилегий** — кому какие ключи доступны.
6. **Регистрация RFID ключа** — метка на каждом физическом ключе.
7. При необходимости — **секретные коды** для сдачи без входа.

---

## Связь с пользовательской программой

| Настройка в админке | Эффект для пользователя |
|---------------------|-------------------------|
| Пользователь + RFID | Может войти по личной метке |
| Привилегии на ключ | Ключ виден в «Взять ключ» |
| RFID на ключе | Сдача по метке ключа; распознавание при взятии |
| Секретный код | Сдача с гостевого экрана без входа |
| Позиция ключа в боксе | Открывается правильная ячейка шкафа |

---

## Если что-то не работает

| Проблема | Действие |
|----------|----------|
| Не подключается к базе | Проверить, что PostgreSQL запущен (см. `deploy/КАК_УСТАНОВИТЬ.md` для сервера). |
| Не подключается к шкафу | В `config.cfg`: `device_host`, `device_port` — IP и порт контроллера. |
| RFID не читается | Проверить `host`/`port` в секции `[rfid]`; считыватель и кабель. |
| Пользователь не видит ключи | Выдать привилегии; ключ назначен на бокс; пользователь привязан к боксу (если используется). |
| Ячейка не та | Проверить координаты ключа в «Назначить ключи на бокс». |

---

## Кнопки на формах

На большинстве экранов:
- **Назад** — возврат в админ-меню без сохранения (или с сохранением, если уже нажали «Создать»/«Сохранить»).
- **Создать** / **Сохранить** — применить введённые данные.
