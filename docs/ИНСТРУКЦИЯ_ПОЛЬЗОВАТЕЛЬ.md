# Ключница — инструкция для пользователя

Краткое руководство по **пользовательской программе** (экран у шкафа с ключами).

---

## Назначение

Программа позволяет:
- войти в систему по RFID-метке;
- **взять** ключ из ячейки шкафа;
- **сдать** ключ обратно;
- посмотреть, какие ключи сейчас у кого на руках.

---

## Первый экран (до входа)

| Кнопка | Что делает |
|--------|------------|
| **Авторизация** | Вход в систему. Откроется экран «Приложите RFID-метку к считывателю». |
| **Просмотр выданных ключей** | Список всех ключей, которые сейчас выданы. Вход **не нужен**. |
| **Сдать по секретному коду** (внизу) | Сдача ключа без входа в систему — по коду, который выдал администратор. |

---

## Вход в систему (RFID)

1. Нажмите **Авторизация**.
2. Приложите **личную RFID-метку** (карту/брелок) к считывателю.
3. Если метка зарегистрирована — откроется главное меню.
4. Если нет — обратитесь к администратору для регистрации метки.

Кнопка **Назад** — возврат на первый экран.

---

## Главное меню (после входа)

| Кнопка | Что делает |
|--------|------------|
| **Взять ключ** | Показать ключи, к которым у вас есть доступ. Выберите нужный — откроется ячейка в шкафу. |
| **Сдать ключ** | Показать ключи, которые вы взяли. Выберите ключ для сдачи. |
| **Просмотр выданных ключей** | Общий список выданных ключей (всех пользователей). |
| **Выход** (внизу) | Завершить сеанс и вернуться на первый экран. |

При долгом бездействии программа сама выйдет из учётной записи (таймаут задаёт администратор).

---

## Взять ключ

1. Нажмите **Взять ключ**.
2. На экране — плитки с названиями помещений/ключей.
3. Нажмите на нужный ключ **или** приложите RFID-метку **этого ключа** к считывателю.
4. Ячейка в шкафу **откроется**, ключ регистрируется как выданный вам.
5. Заберите ключ и закройте ячейку (замок закроется автоматически через несколько секунд).

**Навигация:** «Назад» — в главное меню; «Предыдущая» / «Следующая» — если ключей много и они на нескольких страницах.

---

## Сдать ключ

1. Нажмите **Сдать ключ**.
2. Выберите ключ из списка **ваших** выданных ключей.
3. Появится сообщение: **«Поднесите ключ к общему RFID-считывателю»**.
4. Приложите **метку на ключе** (не личную карту) к считывателю.
5. После проверки откроется нужная ячейка — положите ключ внутрь.

> Сдача с главного экрана **только через этот сценарий** — сначала выбор ключа, потом RFID ключа.

**Навигация:** как на экране «Взять ключ».

---

## Сдача по секретному коду (без входа)

Если нет RFID-метки пользователя, но администратор выдал **секретный код** для конкретного ключа:

1. На первом экране нажмите **Сдать по секретному коду**.
2. Введите код.
3. Выберите ключ для сдачи (если программа попросит).
4. Поднесите RFID-метку **ключа** к считывателю.
5. Положите ключ в открывшуюся ячейку.

---

## Просмотр выданных ключей

Показывает, **кто** и **какой ключ** сейчас держит.

- Доступен **без входа** с первого экрана.
- Доступен **после входа** из главного меню.
- Можно листать страницы, если записей много.

Взять или сдать ключ из этого экрана **нельзя** — только просмотр.

---

## Сообщение «Неверная ячейка»

Появляется, если ключ снят или положен **не в ту ячейку**.

- Выполните действие в **указанной** ячейке.
- Экран закроется сам, когда всё будет сделано правильно, или по таймауту.

---

## Если что-то не работает

| Проблема | Что проверить |
|----------|----------------|
| Не входит по RFID | Метка зарегистрирована у администратора? Метка плотно приложена? |
| Нет ключей в списке «Взять» | Администратор выдал вам доступ к этим ключам? |
| Ячейка не открывается | Связь с шкафом, питание оборудования — сообщите администратору. |
| Окно с ошибкой при запуске | База данных или оборудование недоступны — администратор. |

---

## Краткая шпаргалка

```
Вход:     Авторизация → RFID личной метки
Взять:    Взять ключ → выбрать → забрать из ячейки
Сдать:    Сдать ключ → выбрать → RFID метки ключа → положить в ячейку
Без входа: Просмотр выданных / Сдать по секретному коду
Выход:    кнопка «Выход»
```
